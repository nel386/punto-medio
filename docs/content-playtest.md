# Playtest editorial del contenido

## Alcance

Primera edición curada: 12 categorías, 120 escalas y 240 extremos. Cada categoría contiene 3 escalas familiares, 4 de amigos y 3 adultas.

## Hipótesis

El catálogo debe producir pistas concretas y discusiones con posiciones intermedias. El objetivo no es que exista una respuesta correcta, sino que el grupo entienda rápidamente qué dimensión está colocando y pueda defender su interpretación.

## Muestra recomendada

- Dos grupos casuales.
- Un grupo acostumbrado a juegos de mesa.
- Un grupo adulto que use el tono adulto.
- Una sesión de pareja o grupo pequeño para detectar escalas demasiado personales.

## Registro

Para cada escala se anotará: tiempo hasta la primera pista, número de participantes que intervienen, si alguien pide aclaración, si la aguja se coloca sin debate y si la conversación continúa después de revelar la zona.

Se deben retirar o reformular las escalas que resulten objetivas, confusas, ofensivas, demasiado dependientes de una generación o imposibles de colocar sin conocer una referencia externa.
